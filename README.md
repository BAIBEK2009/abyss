# ABYSS · Карта капитана

Учебная игра (финальный проект AI Fundamentals, QAIRU). Над Каспием пропал вымышленный рейс AQ-271. Капитан научно-спасательного судна «Тұлпар» ищет чёрный ящик на дне раньше соперника «Посейдон-2». Три офицера — три алгоритма из разных тем ИИ: **байесовский вывод** (где вероятнее ящик), **A\*** (курс в обход рифов), **MDP** (хватит ли топлива). Офицеры считают и советуют, решает игрок.

Python считает всё (`core/`, `server.py`), браузер только рисует (three.js, `web/`). Языки: қазақша, русский, English.

## Как запустить

Нужен только **Python 3.9 или новее** — тот, что уже есть в macOS (`python3`), подходит. Интернет не нужен: three.js, шрифты и звуки лежат в проекте, внешних запросов нет. Ничего устанавливать через `pip` не надо — сервер использует только стандартную библиотеку Python.

**macOS, двойной клик.** Откройте папку проекта в Finder и дважды щёлкните **`ABYSS.command`**. Откроется окно Терминала с сервером, а браузер откроет игру на <http://127.0.0.1:8765>. Чтобы выйти, закройте окно Терминала.

> Если macOS при первом запуске скажет, что файл от неизвестного разработчика: щёлкните по `ABYSS.command` правой кнопкой → «Открыть» → «Открыть». Если файл потерял право на запуск (например, после распаковки архива), выполните один раз в Терминале: `chmod +x ABYSS.command`.

**Из терминала** (macOS, Linux, Windows):

```bash
cd путь/к/abyss
python3 main.py          # Windows: py main.py
```

Браузер откроется сам; если нет — откройте <http://127.0.0.1:8765>. Остановить сервер — `Ctrl+C`.

Полезные ключи:

| Команда | Что делает |
|---|---|
| `python3 main.py --lang kk` | сразу на казахском (`ru`, `en`); без ключа игра один раз спросит язык и запомнит |
| `python3 main.py --seed 7` | другая карта (по умолчанию демо-карта 272) |
| `python3 main.py --free` | свободный поиск без сюжетной кампании |
| `python3 main.py --exam` | режим экзамена: каждый ход трёх алгоритмов печатается в терминал |
| `python3 main.py --no-browser --port 8765` | не открывать браузер, другой порт |

Браузер — свежий Chrome, Safari, Firefox или Edge (нужен WebGL 2). Язык меняется в игре: **Esc → Тіл / Язык / Language**.

**Для разработки** (тесты и инструменты скриншотов; игре это не нужно):

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt   # или: uv pip install --python .venv/bin/python -r requirements-dev.txt
.venv/bin/python -m pytest -q
```

Если `.venv` есть, `ABYSS.command` запускает игру из него, иначе — системным `python3`.

## Чужие ресурсы и лицензии

- **three.js r170** (MIT) — `web/vendor/three/`, вместе с аддонами (OutlinePass, RoundedBoxGeometry, BufferGeometryUtils, GTAO, bloom).
- **Шрифты** (SIL Open Font License) — Prata, Onest, Caveat, PT Mono, Cormorant Garamond в `web/fonts/`, тексты лицензий рядом (`OFL-*.txt`).
- **Текстуры дна** (CC0, Poly Haven) — «Coast Sand 02», цвет, нормали и шероховатость 1k в `web/assets/seabed/` (<https://polyhaven.com/a/coast_sand_02>); «Rock Face» (камни, трипланарно) — 1k в `web/assets/rock/` (<https://polyhaven.com/a/rock_face>). CC0 не требует указания авторства, указываем из уважения.
- Всё остальное (модели, текстуры судов и аппарата, звук, музыка) сделано в коде проекта.
