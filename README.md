# ABYSS · Карта капитана

Учебная игра (финальный проект AI Fundamentals, QAIRU). Над Каспием пропал вымышленный рейс AQ-271. Капитан научно-спасательного судна «Тұлпар» ищет чёрный ящик на дне раньше соперника «Посейдон-2». Три офицера — три алгоритма из разных тем ИИ: **байесовский вывод** (где вероятнее ящик), **A\*** (курс в обход рифов), **MDP** (хватит ли топлива). Офицеры считают и советуют, решает игрок.

Python считает всё (`core/`, `server.py`), браузер только рисует (three.js, `web/`). Языки: қазақша, русский, English.

## Что внутри игры

Кампания «Пять суток» (≈25–35 минут), сид 272, маячок ящика работает 120 часов:

| Часть | Время суток | Что нового |
|---|---|---|
| **Пролог** | ночь, 02:40 | палуба «Тұлпара» от первого лица: вызов по рации на мостике, бинокль на место крушения, трап в каюту, штурманский стол |
| **Акт I · Квадрат** | утро | сонар и погружение: пеленгатор маячка, цепочка обломков, закрылок с номером рейса; приходит «Посейдон-2» |
| **Акт II · Шторм** | шторм | фронт шторма идёт по карте (клетка втрое дороже — A\* обходит, сонар глохнет), топливо всерьёз (MDP зовёт в Актау), улика пограничников, **ложный буй** (Байес «Посейдона» верит эху), хвост самолёта, перехват телеграммы |
| **Акт III · Два ящика** | ночь и туман | выбор «Голос / Данные», две кальки вероятностей и переключатель, второй таймер 30 ч у речевого самописца, «Посейдон» может поднять ящик первым, запись последних минут |
| **Акт IV · Правда** | рассвет | «Посейдон-2» борт о борт, сделка Ван дер Берга, моральный выбор |
| **Концовки** | — | газетная полоса: «Правда», «Огласка», «Тишина» или «Опоздали» |

Погода и жизнь: волны Герстнера, дождь, молнии, туман с ревуном, мокрая палуба, чайки, вертолёт и катера у места крушения, радар на мостике с метками из мира. Доска улик «Что случилось с AQ-271» (6 находок, красные нити) — на стене каюты и кнопкой на столе. Пауза (Esc) останавливает весь мир: кислород, часы, соперника. Прогресс сохраняется в браузере — «Продолжить» в главном меню.

## Демо для защиты

`python3 main.py --demo` (или кнопка «Демо для защиты» в главном меню) — сид 272, вся история за ~5 минут: реплики листаются сами через 2,5 с, спуски по 8 с, в каждом акте одна находка, кнопка «Пропустить к следующему акту» вверху. Работает на всех трёх языках. Автопилот за столом (кнопка в шапке) по-прежнему показывает три алгоритма вместе.

## Играть онлайн

**<https://ЛОГИН.github.io/abyss/>** — подставьте логин владельца репозитория на GitHub (для этого репозитория: <https://baibek2009.github.io/abyss/>). Демо для защиты онлайн: добавьте `?demo=1`, язык сразу: `?lang=kk` (`ru`, `en`).

Сервер не нужен: тот же Python-код из `core/` работает прямо в браузере через [Pyodide](https://pyodide.org) (CPython, собранный в WebAssembly). При первом открытии около 5 секунд идёт загрузка Python («Python жүктелуде… / Загружаем Python… / Loading Python…»), Pyodide берётся с официального CDN jsDelivr — для онлайн-версии нужен интернет. Прогресс сохраняется в `localStorage` браузера, как и в локальной игре.

Как устроено: `tools/build_web.py` собирает папку `docs/` (весь `web/` + `core/*.py` + тексты сюжета), все пути относительные. `web/js/api.js` — единственная точка для `/api/*`: локально это `fetch` к `server.py`, онлайн — вызов `core/router.py` (те же маршруты, что у сервера) внутри Pyodide. Логика на JavaScript не дублируется.

```bash
python3 tools/build_web.py                 # пересобрать docs/ после правок в web/ или core/
cd docs && python3 -m http.server 8000     # проверить онлайн-версию локально: http://localhost:8000/
.venv/bin/python tools/online_check.py     # Playwright: демо до концовки на kk / ru / en
```

## Как запустить

Нужен только **Python 3.9 или новее** — тот, что уже есть в macOS (`python3`), подходит. Интернет не нужен: three.js, шрифты и звуки лежат в проекте, внешних запросов нет. Ничего устанавливать через `pip` не надо — сервер использует только стандартную библиотеку Python.

**macOS, двойной клик.** Откройте папку проекта в Finder и дважды щёлкните **`ABYSS.command`**. Откроется окно Терминала с сервером, а браузер откроет игру на <http://127.0.0.1:8765>. Чтобы выйти, закройте окно Терминала.

> Если macOS скажет «Apple could not verify…»: нажмите «Done» → Системные настройки → «Конфиденциальность и безопасность» → внизу «Open Anyway». Запасной путь: в Терминале `python3 ` и перетащить `main.py` в окно. Если файл потерял право на запуск (например, после распаковки архива), выполните один раз в Терминале: `chmod +x ABYSS.command`.

**Из терминала** (macOS, Linux, Windows):

```bash
cd путь/к/abyss
python3 main.py          # Windows: py main.py
```

Браузер откроется сам; если нет — откройте <http://127.0.0.1:8765>. Остановить сервер — `Ctrl+C`.

Полезные ключи:

| Команда | Что делает |
|---|---|
| `python3 main.py --lang kk` | сразу на казахском (`ru`, `en`); без ключа игра один раз спросит язык и запомнит |
| `python3 main.py --seed 7` | другая карта (по умолчанию демо-карта 272) |
| `python3 main.py --demo` | демо для защиты: вся кампания за ~5 минут |
| `python3 main.py --free` | свободный поиск без сюжетной кампании |
| `python3 main.py --exam` | режим экзамена: каждый ход трёх алгоритмов печатается в терминал |
| `python3 main.py --no-browser --port 8765` | не открывать браузер, другой порт |

Браузер — свежий Chrome, Safari, Firefox или Edge (нужен WebGL 2). Язык меняется в игре: **Esc → Тіл / Язык / Language**.

**Для разработки** (тесты и инструменты скриншотов; игре это не нужно):

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt   # или: uv pip install --python .venv/bin/python -r requirements-dev.txt
.venv/bin/python -m pytest -q
```

Если `.venv` есть, `ABYSS.command` запускает игру из него, иначе — системным `python3`.
